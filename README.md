# Design system components

This directory contains simple, reusable React components used across the GitDigital UI projects.

Components included:
- DonateButton: shows Cash App project and personal tip links
- ProgressBar: accessible progress bar
- GoalCard: small card showing a goal's progress
- Heatmap: placeholder SVG heatmap (replace with Nivo/Vega for production)
- MermaidEmbed: simple mermaid renderer (requires mermaid script loaded)
- Footer: example footer with donate links and contact email

Usage: import components from the design-system package or copy files into your project.
